## Ian Chen

我关注工具型 AI Agent 的可靠性，希望通过可信评估、Rubric 质量研究、
轨迹级诊断和受控改进实验，理解 Agent 的行为与泛化能力。

### 研究方向

- **LLM Agent 评估** — 对真实 Agent 行为进行可信测量
- **Rubric 质量** — 评分标准是否衡量了预期行为
- **奖励建模** — 评估与有效学习信号之间的关系
- **强化学习** — 训练信号质量与泛化能力

### 当前工作

[Agent Improvement Lab](../projects/agent-improvement-lab/) 是一个独立的
公开的研究与工程项目，首个阶段是 tau2 Retail 的 Evaluation Harness v0.1 设计。
